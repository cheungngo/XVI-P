\section{Appendix overview}
All listings below are generated by \texttt{tools/build.py} from exactly the source files executed and the certificate files written in this build (ASCII-sanitised copies in \texttt{manuscript/listing\_src}; the build verifies byte-identity after typesetting and again before zipping). Lists of scalars are printed on one line, so a page break cannot split them; page numbers are printed as ``XVI-P p23 | page N'' (one version variable, \texttt{p22\_conventions.VERSION\_LABEL}, written to \texttt{manuscript/version.tex}). The external manifest (with PDF/zip hashes) is written after the PDFs and is deliberately not reproduced inside any PDF.
